# open-eidas

Cette branche (`main`) ne suit que ce qui est **certifié en production** :
elle ne reçoit de commits que par fusion d'une pull request depuis
[`dev`](https://github.com/open-eidas/open-eidas/tree/dev), après
validation d'au moins deux mainteneurs — aucun push direct, aucun
contournement, y compris pour les administrateurs du dépôt.

Le développement actif, le code, la documentation et les instructions
d'installation se trouvent sur
[`dev`](https://github.com/open-eidas/open-eidas/tree/dev). Cette branche
`main` est vide de tout autre contenu tant qu'aucune version n'a encore été
promue en production.

Les numéros de version ([SemVer](https://semver.org/lang/fr/)) sont
attribués sur `dev`, à partir de l'historique des
[Conventional Commits](https://www.conventionalcommits.org/fr/) — voir la
documentation de contribution sur `dev` pour le détail du flux.
